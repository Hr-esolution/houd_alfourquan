Politique de Confidentialité

Houda Al Fourquan

Dernière mise à jour : 10 mars 2026

✅ En résumé : Nous ne collectons ni ne stockons vos données personnelles sur nos serveurs.

1. Introduction

Bienvenue sur Houda Al Fourquan. Cette politique de confidentialité explique comment nous traitons vos données lorsque vous utilisez notre application islamique.

Notre engagement : Votre vie privée est notre priorité. Nous avons conçu cette application pour fonctionner avec un minimum de données et un maximum de confidentialité.

2. Données Collectées

❌ Données NON collectées

Nous ne collectons AUCUNE des données suivantes :

  • Nom et prénom
  • Adresse email
  • Numéro de téléphone
  • Adresse postale
  • Historique de navigation
  • Identifiants de publicité
  • Données de paiement

✅ Données utilisées localement

Les données suivantes sont utilisées UNIQUEMENT sur votre appareil et ne sont JAMAIS transmises :

  • Position GPS : utilisée uniquement pour calculer les horaires de prière et la direction Qibla.
  • Préférences utilisateur : paramètres (méthode de calcul, langue, notifications) stockés localement.
  • Historique de lecture : progression dans le Coran et tasbihs.
  • Compteurs Tasbih : stockés localement.

3. Permissions Utilisées

📍 Localisation (GPS)

Pourquoi ? Calcul précis des horaires de prière et direction Qibla.

Comment ? La position est utilisée uniquement pendant l'utilisation de l'application pour les calculs. Elle n'est pas stockée.

🌐 Internet

Pourquoi ? Télécharger les récitations audio du Coran et les traductions.

Comment ? Connexion uniquement lors du téléchargement. Aucune donnée personnelle n'est envoyée.

🔔 Notifications

Pourquoi ? Rappels pour les prières et l'Adhan.

Comment ? Notifications locales programmées sur votre appareil.

4. Partage de Données

Nous ne vendons, ne louons et ne partageons pas vos données à des fins commerciales.

  • ❌ Pas de publicité
  • ❌ Pas d'analytics
  • ❌ Pas de réseaux sociaux intégrés
  • ❌ Pas de vente de données

Données techniques utilisées uniquement pour la fonctionnalité :

  • ✅ Coordonnées GPS (OpenStreetMap Nominatim)
  • ✅ Adresse IP (ipapi.co, localisation de secours)

5. Services Tiers

L'application utilise les services suivants pour fournir du contenu :

  • Quran.com API : texte du Coran et traductions.
  • EveryAyah.com : récitations audio.
  • OpenStreetMap Nominatim : géolocalisation des villes (coordonnées GPS).
  • ipapi.co : localisation par IP (secours si GPS indisponible).

Important : Aucun compte utilisateur n'est transmis. Ces services reçoivent uniquement les données nécessaires pour fournir la fonctionnalité.

6. Stockage des Données

Où sont stockées vos données ? Toutes vos données sont stockées localement sur votre appareil (iPhone/iPad ou Android).

Combien de temps ? Les données sont conservées tant que l'application est installée. Si vous désinstallez l'application, toutes les données sont supprimées automatiquement.

7. Sécurité

  • ✅ Les données locales sont stockées dans le bac à sable (sandbox) de l'application
  • ✅ Aucune transmission réseau de données personnelles
  • ✅ Connexions HTTPS sécurisées pour le téléchargement de contenu

8. Droits des Utilisateurs

  • Droit d'accès : vous pouvez voir toutes vos données dans l'application.
  • Droit à la suppression : désinstallez l'application pour supprimer toutes vos données.
  • Droit à la portabilité : non applicable (pas de données collectées).
  • Droit d'opposition : désactivez la localisation dans les paramètres de votre appareil.

9. Enfants et Vie Privée

  • ✅ Ne collecte aucune donnée personnelle
  • ✅ Ne cible pas spécifiquement les enfants de moins de 13 ans
  • ✅ Conforme à la loi COPPA

Les enfants peuvent utiliser l'application en toute sécurité car aucune donnée n'est collectée ou transmise.

10. Modifications de cette Politique

Nous pouvons mettre à jour cette politique de confidentialité. La date de "Dernière mise à jour" indiquera la date de la dernière modification.
